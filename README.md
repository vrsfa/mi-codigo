# mi-codigo

- Es una carpeta donde se registra todo el progreso en mi proyecto de aprendizaje sobre programacion. En este se encuentran lo ejercicios de cada clase registrado por fases y temas.

## Organizacion

```
mi-codigo/
|-fase-0/
|-fase-1/
|-fase-2/
|-fase-3/
|_proyectos/
```

## archivos

- comandos.md: Es una chuleta de comandos donde se regitra cada comando a medida que es neceario. Su funcion es dar facilidad a la tarea de buscar comandos en instantes futuros.
- .gitignore: Es un archivo donde se inidica todo aquello que git debe ignorar. Asi poder tener a salvo informacion que solo el desarrolador debe tener.
- README.md: Es la carta de bienvenida para todo aquel colaborador que entre al repositorio del proyecto. Sirve para dar a conocer la estructura del programa y repositorio.
